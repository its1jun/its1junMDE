## Markdown Syntax

Type the syntax and it converts as you type.

| Type | Result |
| --- | --- |
| `# ` / `## ` / `### ` | Heading 1 / 2 / 3 |
| `**text**` | Bold |
| `*text*` or `_text_` | Italic |
| `~~text~~` | Strikethrough |
| `` `text` `` | Inline code |
| `- ` or `* ` | Bullet list |
| `1. ` | Numbered list |
| `> ` | Quote |
| ` ``` ` | Code block |
| `---` | Horizontal line |
| `![alt](path)` | Image |
| `[text](url)` | Link |

Links and images can also be inserted from the right-click menu. Tables can be inserted from the right-click menu. Selecting Markdown table text also shows a **Convert to Table** button.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl + S | Save |
| Ctrl + O | Open a file |
| Ctrl + N | Open a new window |
| Ctrl + T | Open a new tab |
| Ctrl + W | Close the active tab |
| Ctrl + F | Find text in the document |
| Alt + → / Alt + ← | Switch to the next / previous tab |
| Ctrl + B / Ctrl + I | Bold / Italic |
| Ctrl + Z | Undo |
| Ctrl + Y / Ctrl + Shift + Z | Redo |
| Ctrl + Mouse Wheel | Zoom in / out |
| Ctrl + 0 | Reset zoom to 100% |
| Tab / Shift + Tab | Move to the next / previous table cell |
| Ctrl + Click | Open a link in the default browser |
| Double-click an image | Reset its size |
| Right-click | Open the context menu for file actions or inserting/editing tables, links, and images |
| Select text | Show the formatting toolbar |

## Additional Features

- **Code blocks:** Hover over a code block to show the copy button.
- **Tables:** Right-click inside a table to toggle the header, insert or delete rows and columns, or delete the table.
- **Links:** Right-click a link to edit or delete it.
- **Images:** Drag the bottom-right handle to resize an image. Right-click an image to delete it.
