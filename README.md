## Markdown Syntax

Type the syntax and it converts as you type.

| Type | Result |
| --- | --- |
| `# ` / `## ` / `### ` | Heading 1 / 2 / 3 |
| `**text**` | Bold |
| `*text*` or `_text_` | Italic |
| `~~text~~` | Strikethrough |
| `` `text` `` | Inline code |
| `- ` or `* ` | Bullet list |
| `1. ` | Numbered list |
| `> ` | Quote |
| ` ``` ` | Code block |
| `---` | Horizontal line |
| `![alt](path)` | Image |

Links and tables are added from the right-click menu (Insert Link, Insert Table). Selecting Markdown table text also shows a Convert to Table button.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| Ctrl + S | Save |
| Ctrl + O | Open a file |
| Ctrl + N | New window |
| Ctrl + T | New tab |
| Ctrl + W | Close tab |
| Alt + → / Alt + ← | Next / previous tab |
| Ctrl + B / Ctrl + I | Bold / Italic |
| Ctrl + Z | Undo |
| Ctrl + Y / Ctrl + Shift + Z | Redo |
| Tab / Shift + Tab | Next / previous table cell |
| Ctrl + Click | Open a link |
| Double-click an image | Reset its size |
| Right-click | Open the menu (file actions, insert table / link / image) |
| Select text | Show the formatting toolbar |
